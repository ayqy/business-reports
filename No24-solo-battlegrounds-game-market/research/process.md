# 研究过程、样本边界与决策链

研究问题：以中国个人开发者身份制作“经典酒馆战棋怀旧复刻 + 全 AI 对手 + 售卖英雄选项/重掷通行证”，能否凭真实可触及的市场和可复制的付费闭环，稳定取得每月人民币1万元税前业主利润？核验时点：2026-09-25（北京时间）。

## 先证伪的四个条件

1. 中国大陆区的作品和运营主体能否合法、可负担地发布？查 Apple 中国区材料和国家新闻出版署清单，不能把免费或单机当豁免。
2. “最经典版本 + 关键卡牌成长机制 + 玩家昵称”是否仍是平台可接受的原创？查 Apple 4.1/5.2、暴雪官方现行权益；新画风并不覆盖整个表达和识别风险。这里评估的是审核与权利风险，不对尚未制作的产品作侵权法律判决。
3. 有没有近年的中国市场增量和付费需求？查游戏工委2025全年、网易2025与2026上半年、官方《月圆之夜》供给与 Apple 中国区玩家留言。剔除“整个中国移动游戏规模等于本细分规模”的错误外推。
4. 在独立开发者获取流量的限制下，通行证是否能形成月利润1万元？以公开价格锚点、Apple 条件费率、**明确假设**构造季票和买断反算；未知转化/CAC/续费不能当实测。

## 可重跑的采样与排除

- `collect_apple_sample.py` 在 Apple 中国区 Search API 以 `卡牌自走棋`、`酒馆战棋`、`背包乱斗`、`自走棋 单机` 查询，`entity=software&limit=200`。原始 API 的动态元数据被压缩为 `apple-cn-search-snapshot.json`，保留每条的应用链接。`自走棋 单机` 返回82项，其中70项标为游戏、24项累计评分不超过100；其余结果混有飞行棋、棋牌、塔防、RPG等，并非严格同类。**这不是随机样本，不能说“市场上24/70的产品失败”。**
- 精确产品比较限于官方站/商店页能核对的《炉石传说》《月圆之夜》《弈仙牌》《魔卡棋旅》《斗阵骑士》《永恒徽章-自走棋》《背包乱斗》等。具体可见价格、版本日期和累计评分，不能算总收入。2026-09刚上线的产品与2017年的老产品评分不具有同龄可比性。
- `collect_review_sample.py` 留存 Apple RSS 最近一页两款应用各50条评论。抓取窗口不是随机抽样、会随时间变化；长篇负面评论可能被放大。《月圆之夜》7/50包含“单机”，本报告只把文字作为存在某些用户偏好的**定性证据**，不把14%宣称为所有玩家需求比率。
- 搜索中国自走棋停运案例时出现代理、搜索引擎验证码与无一手经营数据。未经直接核实的停运消息、第三方估算流水、把代理移交当作整个产品失败，均不用于量化判断。保留 Valve 对策略卡牌《Artifact》停止继续开发的第一方公告，明确其地理范围是全球，作为失败机制参考。

## 三角核验与推导

- 全国口径 M01 与网易 M02/M03 指向“整体游戏支出和头部公司游戏收入仍增长”，但样本口径不同，不能相加或推出小产品的增长率。
- 网易公告仅写暴雪在华游戏年度收入创新高、**未拆《炉石》或酒馆战棋单模式利润**；暴雪 M04/M05 给出了英雄选项与重掷的确切权益。两者结合只证明原产品有这种商业化并保持运营，不证明独立单机复制能卖出同等付费率。
- 巨人旗下《月圆之夜》官网 M06 与中国区商店 M07 相互印证长期存在和更新，M08 评论提示存在单机偏好；它是已建立版权、分发、出版与社区能力的成功案例，不能按其声量预测个人首作。
- `model.py` 的所有商业输入和公式公开，生成 `model-results.json`。人数、订单、毛额、平台扣费、退款、固定成本、业主税前利润依次闭合；中国出版合作、许可和个人所得税未得到可核报价，因此故意**不写成已包含**。未来市场情景以2025全国移动游戏收入为基线，增长率是推断区间；单机酒馆战棋细分因无可信基线，无法给出负责任的绝对人民币预测。

## 决策门槛

只有同时取得：(a)原创设计/权利审查与明确可用的发行区域及合作架构，(b)真实用户的重复游戏及付费测试，(c)在实际收款、退款和获客成本下连续多个季度达到模型要求的净贡献，才可把“稳定月入1万元”列入经营计划。当前无这些实测，故本次结论为**原提案不建议制作和商业化**；“改成有自身机制的原创离线策略游戏”是一条另需验证的替代方向，不等同于已评估可行。最初以“商业评估可行”为前提的 `$scan` 详规条件当时未触发；管理员2026-09-25（北京时间）后续明确破格要求，已将[独立规格与证据](../scan/functional-spec.md)列为新交付，不回写改变本研究结论。
