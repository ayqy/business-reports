## 同刻死亡顺序的核验条件

H14/H15 提供了原版画面，但本轮抽样与 `01:01:30–01:03:00` 连续片段均不能同时辨认：攻击方和防守方的战前站位、双方同次打击后死亡的单位、各自的亡语、仍活的友军死亡触发、空格和召唤最终位置。因此[社区模拟器的“第 0 方先结算、亡语先于友军死亡触发”](historical-2019-mechanics.md)仍只是其源码事实。若取得能裁决的录像或日志，应为每个测试向量保存 `build / match_time / source_unit / target_unit / pre_board / event_seq / post_board / video_timestamp_or_log_offset`，先比较两种参考顺序是否会产生可见分歧，再以原版画面裁决。缺其中任一关键字段的片段只能支持较弱的局部观察。

## 可实施性复审

本轮把“仅有录像页面”推进到**可校验的原始录像与连续片段**：H14 的原始文件哈希已和档案核对，H15 直接证明斯尼德出现在一次六星发现候选中、玩家实际选扎普。这个实见样本**没有**给出斯尼德亡语召唤结果，也没有裁决七个争议 ID 或同刻死亡顺序；本轮未得完整服务端候选、权重与构建号。故 [历史规格的 `exact_2019` 门禁](historical-2019-mechanics.md#9-精确复刻可实施性审查)保持：**可开发带版本与证据标记的参考模拟；不可据现有材料验收与首版逐卡概率、逐事件顺序一致的精确复刻**。公开发行的权利与审批判断仍由[市场报告](../report.md)独立约束。
