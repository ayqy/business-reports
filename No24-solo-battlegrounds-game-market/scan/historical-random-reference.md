# 16 张随机／发现／进化卡：可执行参考裁决

**核验日：2026 年 9 月 26 日（北京时间）。** 对象是 `15.6.0.35747` 上线周的研究支线。此处只提供**明确标为参考实现**的单事件解析，用于程序原型和验收；不声称得到了当年服务端的候选资格、权重或同刻事件顺序。

## 数据和证据边界

| 输入 | 可直接支持的事实 | 在本实现中的角色 |
|---|---|---|
| [32 份普通／金色卡面](historical-random-effect-shells.json)及 H04 固定构建 `CardDefs.xml` | 触发词、请求次数、伤害／强化数值；钢铁武道家卡面没有“随机” | 先运行意图外壳；`exact_mode` 仍报 `unknown_*` |
| [同期社区模拟器](historical-community-simulator-pools.json)，提交 `ec2733704590c4de8c02ad7488d7fabe5a779506` | 它自己的五个固定数组共 9／10／14／22／12 个 ID | **参考配置**的原费用 1／2／4、亡语、传说召唤池；不代表暴雪服务端 |
| [81 张商店研究表](historical-card-pool.json) | 同构建客户端 ID、种族与商店研究名单 | **参考设计**的泽鲁斯变形 80 张、鱼人发现 9 张；`ALL` 算鱼人，均未获原版生成资格证明 |
| H04 中 `UNG_999t*` 十个进化选项实体 | 选项 ID、中文文字及对应静态效果定义；固定 XML 的哈希可复核 | **参考设计**将这十个实体作为选项池；原版温顺的巨壳龙实际提供哪些选项仍未知 |

[参考配置](historical-random-reference.json)逐卡记录候选来源、选择策略和十个进化效果；[66 个普通／金色向量](historical-random-reference-vectors.json)及[运行器](verify_historical_random_reference.py)覆盖全部 16 张卡。向量包括七格已满或只剩一格、无候选、圣盾抵伤、伤害第二次重新选目标、全种族单位在不同种族步骤重复获益、鱼人发现选项去重／`ALL` 入选／手牌满、泽鲁斯保留普通或金色形态、进化两次选择，以及精确模式和同刻死亡拒绝裁决。泽鲁斯在此只解析**孤立事件**：`form` 只是意图标签，不创建金色实体；跨轮手牌来源、金色实体缺失、奖励与拒绝边界另由[招募转换专项审查](historical-recruitment-zerus-audit.md)及 15 个向量处理，两处共用同一 80 项研究候选顺序。外壳另有 66 个只核卡面意图的向量，二者不可混同。

蛮鱼斥候在这份随机参考中也只返回**孤立发现意图**。实际出牌条件、逐次取得手牌牌、金色双次发现与待领取三合一奖励现由[招募转换专项审查](historical-recruitment-murloc-audit.md)及 19 个向量处理；两处使用同一九项研究候选顺序，但都不证明原版发现池。

温顺的巨壳龙在此也只解析**孤立进化意图**。实际出牌、十项选项的类型化效果记录、普通／金色一／两次选择、鱼人及 `ALL` 目标、三合一奖励与拒绝边界现由[招募转换专项审查](historical-recruitment-adapt-audit.md)及 27 个向量处理。三种数值强化写入招募状态；另七种效果已通过[有界战斗接线](historical-combat-adapt-audit.md)核对逐击、临时效果和终局。所有路径都不证明原版进化选项资格、权重或事件顺序。

运行器采用**由调用方给定的合法均匀索引**；每次选择都在当时的候选集上取索引。召唤请求按次结算且受七格上限截断，参考池与商店库存无关、可重复抽中同 ID；成功召唤数可能小于卡面请求数。金色发现／进化连续作独立选择；进化对同一初始鱼人快照施加。钢铁武道家在参考实现中确定性选择最左侧另一台机械。以上都是独立产品的设计取舍，并非同构建原版实测。战斗批次中同时死亡的事件顺序仍拒绝裁决。

可在业务仓库根目录运行 `rtk python No24-solo-battlegrounds-game-market/scan/verify_historical_random_reference.py --carddefs <已校验的 35747 CardDefs.xml>`；`--carddefs` 可选，传入时验证 XML 的固定 SHA-256、十个进化实体文字和植物 1/1 属性。不传 XML 时仍检查已有来源文件、候选集以及所有参考向量。原版精确重放仍须取得带构建号、可归因的生成或选项记录及完整资格／权重配置；一次可见产物只能证实那一次的正资格。
